# NH World AI Agent

A Python and Flask-based AI automation project demonstrating
an AI chat interface, file cleaning, project intelligence,
security checks, and automated testing.

## Features

- Flask web application
- AI provider configuration through environment variables
- CSV and Excel cleaning workflow
- Project analysis and security scanning
- Automated tests for core functionality
- Owner authentication support

## Technology

- Python
- Flask
- SQLite (where configured)
- HTML and JavaScript
- Pytest-compatible tests

## Run Locally

1. Install Python 3.11 or newer.
2. Create and activate a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Configure required environment variables securely.
5. Start the application using the project's supported entry point.

## Security

Never commit API keys, passwords, private keys, production databases,
or private user data. Use environment variables for secrets.

## Demo Notice

This is a portfolio demonstration. Production credentials and
